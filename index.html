Gemini EdgeOne Proxy

Go 1.22+ EdgeOne Pages MIT 零外部依赖

将 Google Gemini API 包装为多格式代理，部署于 EdgeOne Pages 全球边缘节点。 支持 OpenAI Chat Completions、OpenAI Responses API、Gemini 原生三种格式， 多 Token 智能轮询，遇限流自动切换。

API 端点

POST/v1/chat/completionsOpenAI 旧格式
POST/v1/responsesOpenAI 新格式
POST/v1beta/models/{model}:generateContentGemini 原生
POST/v1beta/models/{model}:streamGenerateContentGemini 流式
GET/v1/models模型列表

环境变量

变量用途
APIKEY用户聚合密钥，仅做校验，不发给 Google
TOKEN1真实 Gemini API Key，轮询使用
TOKEN2备用 Key，遇 429 自动切换

快速测试

curl -H "Authorization: Bearer $APIKEY" -d '{"model":"gemini-2.5-flash","messages":[{"role":"user","content":"hi"}]}' /v1/chat/completions
